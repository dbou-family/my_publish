    Synchronisation GitHub

    Les recettes sont stockées dans bdd recette/recettes.json sur la branche recipes-data. Un jeton GitHub avec accès en écriture au dépôt est nécessaire sur chaque ordinateur.

    Créez un jeton limité à ce dépôt avec la permission Contents: Read and write. Il est conservé dans le stockage local de ce navigateur.
